Everything the Day 5 labs use. Get the whole folder into CloudShell with git clone, then cd labs/day5 && chmod +x */*.sh. Every lab has its own cleanup.sh.

Sandbox only

These scripts deliberately create vulnerable IAM principals and simulate attacker activity. Run them only in the course sandbox accounts from Lab 0.
